# Translation rules (EN -> IT) for the e-FEM strategy hub

Audience: Italian marketing and engineering professionals (e-FEM srl, Parma). Register: professional, clear, direct Italian ("tu" never; impersonal or "voi"/infinitive style for actions). Keep it natural, not literal.

KEEP EXACTLY AS-IS (do not translate):
- Anything already in Italian (Italian quotes, Italian FAQ entries, Italian keywords, Italian page titles like "Simulazione Senza Mesh").
- Search keywords/queries in English (they are English-market search terms), product and brand names (MeshFree, NFX, MIDAS MTS, Simcenter Simsolid, Ansys, Abaqus, SolidWorks, G2, Capterra...), URLs, domain names, file paths, code, JSON-LD, HTML attributes, ids, class names, href values, numbers, currency figures.
- The English Reddit outreach template (it is posted on English subreddits).
- Works-cited titles and URLs (bibliographic data stays in original language). Translate only the heading "Works cited" -> "Fonti citate".
- Established English technical/marketing terms Italians use as-is: SEO, AEO, GEO, LLM, CFD, FEA, FEM, TCO, schema, JSON-LD, hreflang, backlink, link building, pillar page, landing page, review, ranking, query, snippet, entity, Share of Voice, HPC, etc. Translate the surrounding sentence normally.

STYLE (hard rules):
- No em dashes (—) and no en dashes used as punctuation. Number ranges like 5–10 may keep the en dash. Use commas, colons, full stops, parentheses.
- No semicolons.
- Preserve all HTML tags, attributes, entities and structure exactly; only translate human-readable text nodes and human-readable attribute values like placeholder, aria-label, title, alt.
- Do not add or remove content. Do not summarise.
